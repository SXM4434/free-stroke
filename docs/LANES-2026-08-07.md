at the default *not one line of the feature executes*; and **`dS/da = 1/T` is one constant for the

channel. `uniformSlope` is *computed*, not assumed, so a later per-stroke speed cannot break it
silently. Groups are first-class via `unit`, off `assignLetters` — the ink's own law, not a table.
