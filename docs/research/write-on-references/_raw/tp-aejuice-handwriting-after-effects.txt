# Animating Handwriting in After Effects

## Main Approaches

The guide outlines eight essential methods for creating animated handwriting effects:

1. Font Selection: "Choose a font that resembles handwriting to create a realistic effect. Fonts like 'Brush Script' or 'Marker Felt' work well"

2. Hand-Drawn Text: Using the pen tool to manually trace letters creates a more organic appearance than standard text layers.

3. Trim Paths: The article recommends applying the Trim Paths effect and animating the end value to "reveal the strokes gradually."

4. Wiggle Expression: Adding subtle movement variations using the expression "wiggle(freq, amp)" simulates natural handwriting imperfections.

5. Keyframe Animation: Experimenting with timing and spacing while using ease in/out functions (F9) creates realistic acceleration effects.

6. Visual Enhancement: Applying glows or blur effects adds depth to the animation.

7. Timing Refinement: The Graph Editor helps fine-tune speed curves for smooth transitions.

8. Audio Design: Adding pen-writing sound effects enhances realism and viewer engagement.

## Trim Paths in Context

Trim Paths is presented as one of eight techniques, used in combination with font selection, hand-drawn geometry, and motion refinement. The article does not discuss limitations of trim paths or suggest alternative methods—it presents trim paths as a recommended technique for this type of animation work.
